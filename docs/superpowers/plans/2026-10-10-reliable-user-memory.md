# Reliable User Memory Implementation Plan

> Execute inline using executing-plans, with TDD; owner waived independent review.

**Goal:** Restore reliable, owner-controlled memory across chats and models, with bounded LLM retrieval tools.
**Architecture:** Structured Postgres memory and source links, durable leased extraction, authenticated controls; shared retrieval powers automatic context and gateway tool calls.
**Tech Stack:** Supabase Postgres/Edge Functions, TypeScript/Deno, React/Vitest.
**Spec:** docs/superpowers/specs/2026-10-10-reliable-user-memory-design.md

## Global Constraints

Preserve source messages/legacy summaries; server-bound identity, enabled providers and budget caps; mobile bypass. $1 cumulative live test budget. Two tool invocations, eight results, 1,500-token context. Three extraction attempts, atomic timestamp/UUID cursor, no unlimited backfill. Native gateway tool support only where implemented; other protocols use automatic retrieval.

## Review Focus

Cross-owner source IDs/cursor tampering; worker/save/forget races; missing usage and HTTP failure; tool calls exhausted/malformed; old/no-match/Unicode retrieval.
